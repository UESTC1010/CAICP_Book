# 示例代码运行说明

本目录汇集第二、四、六、七、八章的全部 Python 代码，共 104 个代码段。每章文件按正文顺序组织，前面的导入和变量定义供后面的代码使用。第一、三、五章以文字、数学和图表讲解为主，没有 Python 代码块。

使用 Python 3。第二、四、六章使用 Python 自带功能；第七章使用 NumPy、Pandas、Matplotlib、scikit-learn 和 jieba，第八章的注意力示例使用 NumPy。安装第三方库时，在终端中执行：

```text
python -m pip install numpy pandas matplotlib scikit-learn jieba
```

这里的 `python` 应对应准备运行示例的环境。如果电脑使用 `python3` 命令，就把安装和运行命令中的 `python` 一并改成 `python3`。

在终端中进入本“代码”目录，再运行相应文件，例如：

```text
python 第七章示例.py
```

第二章运行到 `input()` 时会等待键盘输入，可以输入整数 `12` 并按回车继续。读取文件的例子使用本目录下的 `data/records.txt`。在编辑器中运行时，也应把工作目录设置为本“代码”目录，使相对路径能够找到该文件。

第七章依次绘制四幅图，并保存为 PNG 文件。普通桌面环境中的 `plt.show()` 可能等待图形窗口关闭后才继续，看完后关闭窗口即可。鸢尾花数据集由 scikit-learn 自带，不需要另行下载。

代码已按章连续运行，并检查排序结果、网络输出、梯度更新、池化、标准化、模型选择和注意力计算等关键结果。核对环境为 Python 3.12.14、NumPy 2.3.5、Pandas 2.2.3、Matplotlib 3.11.1、scikit-learn 1.9.0、jieba 0.42.1。此处记录的是实际核对环境，不表示只有这些版本能够运行。小数末位、字体、图形外观和部分输出排列可能随环境改变，应结合书中说明判断。
